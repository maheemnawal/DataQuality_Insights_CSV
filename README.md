# Data Quality & CSV Operations

## Description
This project uses Python and Pandas to clean, analyze, visualize, and manipulate sales data.

## Tasks Completed
- Inspected and cleaned the sales dataset.
- Handled missing values and duplicates.
- Calculated revenue by region and category.
- Created two charts and identified key findings.
- Added 5% tax to revenue.
- Increased Books prices by 10%.
- Updated and exported CSV files.

## Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Files
- `sales_raw.csv` – Original dataset
- `cleaned_sales.csv` – Cleaned dataset
- `sales_updated.csv` – Updated dataset
- `sunday_project.ipynb` – Project notebook
